# 🚀 MonCV.ai — AI CV Generator SaaS
### Plateforme SaaS d'Excellence & Portfolios Web Certifiés ATS
> Conçue, Développée et Propulsée par **INNOVA GROUP**

---

## 🌟 Présentation du Projet

**MonCV.ai** est une plateforme SaaS de nouvelle génération dédiée à l'accélération de carrière et au recrutement haut de gamme. Elle combine l'intelligence artificielle pour la génération de CV conformes aux algorithmes ATS (*Applicant Tracking Systems*), des lettres de motivation percutantes selon la méthode STAR, des demandes d'emploi officielles aux standards administratifs, ainsi qu'un studio de **Portfolios Web d'Élite** (*Atelier Digital*) calibré selon les standards internationaux du web design (*Awwwards, Linear, Vercel*).

---

## 🎯 Fonctionnalités Clés

### 1. 📄 Générateur de CV Certifié ATS
- Score de compatibilité ATS en temps réel avec analyse des mots-clés.
- Formats et rubriques personnalisables (Expériences, Compétences, Diplômes, Certifications, Langues, Références).
- Export PDF haute fidélité aux dimensions standard A4.

### 2. 🌐 Studio de Portfolios Web d'Élite (Atelier Digital)
- 11 sections interactives : Hero immersif, Monogramme de marque, À propos, Compétences interactives, Showcase de projets, Timeline d'expériences, Grille tarifaire & prestations, Témoignages et contact direct WhatsApp/Mail.
- Double thème instantané : Mode Sombre (*Dark Mode Cyberpunk/Linear*) et Mode Clair (*Light Minimalist*).
- Zéro retour à la ligne involontaire (`whitespace-nowrap`), animations au survol (*micro-interactions, scale, glow, rotations*).
- Accès direct à l'URL publique du candidat : `/c/[slug]`.

### 3. 📝 Demandes d'Emploi & Lettres de Motivation STAR
- Formats officiels et protocolaires pour les entreprises privées et institutions publiques.
- Assistant IA basé sur la méthode **STAR** (*Situation, Tâche, Action, Résultat*).

### 4. 💳 Monétisation & Paiements Sécurisés
- Tarification transparente sans abonnement caché.
- Prise en charge native des moyens de paiement Mobile Money populaires : **Wave, Orange Money, MTN MoMo, Moov Money**.

### 5. 🏛️ Conformité Juridique & Support Dédié
- Conditions Générales d'Utilisation complètes (`/terms`) conformes au RGPD et législations africaines.
- Section et page dédiées « Nous Contacter » (`/contact`) avec support WhatsApp direct 7j/7 assuré par **INNOVA GROUP**.

## 🛠️ Stack Technologique

- **Framework** : [Next.js 14 (App Router)](https://nextjs.org/)
- **Langage** : [TypeScript](https://www.typescriptlang.org/)
- **Styling** : [Tailwind CSS](https://tailwindcss.com/)
- **Icônes** : [Lucide React](https://lucide.dev/)
- **Génération PDF** : `html2pdf.js` / Canvas natif
- **Persistance** : LocalStorage & SessionStorage sécurisé

## 🚀 Installation & Démarrage Local

```bash
# Cloner le dépôt
git clone https://github.com/<votre-username>/AI-CV-Generator-SaaS.git
cd AI-CV-Generator-SaaS

# Installer les dépendances
npm install

# Démarrer le serveur de développement
npm run dev
```

Ouvrez [http://localhost:3000](http://localhost:3000) dans votre navigateur.
